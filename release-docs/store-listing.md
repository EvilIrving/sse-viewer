# Store listing

## Short description

Capture and inspect Server-Sent Events in a dedicated local DevTools panel.

## Long description

SSE Inspector adds a DevTools panel for developers working with Server-Sent Events. It groups active streams, shows messages in time order, formats JSON, supports filtering and provides data, headers and raw views. Stream content remains in the browser and is not transmitted to an external service.

## Submission facts

Category: Developer Tools. Single purpose: locally inspect SSE traffic in the user-selected DevTools tab. Permissions: `scripting` injects the observer, `storage` saves interface preferences and `<all_urls>` covers the developer’s selected page. Data collection: none. Privacy policy: `https://evilirving.github.io/sse-viewer/privacy.html`. Support: `https://github.com/EvilIrving/sse-viewer/issues`.
