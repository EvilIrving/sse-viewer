# 发布说明

商店文案、权限说明与隐私链接以 `release-docs/store-listing.md` 为准；完整发布步骤以 `release-docs/release-checklist.md` 为准。每次发布先运行 `npm run release`，再用生成的 Chrome 与 Edge ZIP 完成手工冒烟验证。

公开站点由 `docs/` 部署到 GitHub Pages，隐私政策地址为 `https://evilirving.github.io/sse-viewer/privacy.html`。不要沿用旧的 `privacy-policy.html` 权限表述；该页面仅保留为指向当前政策的兼容跳转。
