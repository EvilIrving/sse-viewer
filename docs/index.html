SSE Inspector

A dedicated browser panel for following real-time messages while you work.

View releasesPrivacy

Stay with the message flow

Open the browser’s developer tools, select SSE Inspector and refresh the page. The panel keeps related messages together and makes recent activity easier to review.

Install

Download the Chrome or Edge package from GitHub Releases, unzip it and load the folder from your browser’s extension management page. Read the installation guide for details.

Privacy

The information shown in the panel stays in your browser session and is not sent to an external service.
