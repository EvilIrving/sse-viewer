SSE Inspector

A DevTools panel for inspecting Server-Sent Events, EventSource and streaming fetch responses locally.

View releasesPrivacy

Inspect streaming traffic

Open DevTools, select SSE Inspector and refresh the page. The panel groups streams, formats JSON payloads and offers filtering, raw data and headers without sending captured content to a server.

Install

Download the Chrome or Edge package from GitHub Releases, unzip it and load the folder from your browser’s extension management page. Read the installation guide for details.

Scope

The extension uses broad host access only after you open its DevTools panel so it can inject a local SSE observer into the tab you chose.
